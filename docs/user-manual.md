## Getting Started

- Go to the CurriculumBank website.
- Log in with your Google account.
- Your role (teacher or student) will determine your available features.

## Accessing Curriculum Files

- After logging in, you will see a list of available curriculum files.
- Each file displays its title, description, tags, uploader, and upload date.

## Searching and Filtering

- Use the search bar to find curriculum files by title, description, or tags.
- Use tag filters to narrow down results by subject or grade.

## Previewing and Downloading Files

- Click on a curriculum file to view its details.
- For PDF files, you can preview the document directly in your browser.
- Click the **Download** button to download the file to your device.

## Uploading Curriculum Files (Teachers)

- Teachers can upload new curriculum files using the **Upload** button.
- Fill in the required fields: title, description, tags, and select the file to upload.
- Click **Upload** to add the file to the system.

## Editing and Deleting Files (Teachers)

- Teachers can edit or delete files they have uploaded.
- Use the **Edit** button to update file details or replace the file.
- Use the **Delete** button to remove a file from the system (confirmation required).

## Error Handling and Troubleshooting

- If an error occurs (e.g., failed to load files, failed to upload), an error message will be displayed at the top of the page.
- If you encounter persistent issues:
  - Check your network connection.
  - Ensure you are logged in with the correct account.
  - Contact your administrator or technical support if problems persist.
